# GitHub Copilot Instructions for MovieVault API

## Git Commit Messages

When generating commit messages or suggesting commits:

1. **Always follow Conventional Commits format**: `<type>: <description>`

2. **Allowed types**:
    - `feat` - Add a new feature or API endpoint
    - `fix` - Fix a bug or issue
    - `refactor` - Improve code without changing functionality
    - `docs` - Update documentation or README

3. **Requirements**:
    - Write in **English only**
    - Start with **lowercase** (except proper nouns)
    - Keep under **50 characters** total
    - Use **imperative mood** (e.g., "add", not "added" or "adds")
    - **No periods** at the end
    - Be **specific to the MovieVault API** project (functions, endpoints, handlers)

4. **Examples for this project**:
    - ✅ `feat: add deleteMovie endpoint`
    - ✅ `fix: resolve undefined response in addFavorite`
    - ✅ `refactor: extract response handler to separate module`
    - ✅ `docs: update API endpoint list`

5. **For complex changes**, optionally add a body after a blank line with more context.

**Reference**: See `.github/COMMIT_GUIDELINES.md` for detailed guidelines.
